# Cloud brand assets

Source: [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons), downloaded 2026-09-21. SVG geometry is unchanged. The AWS mark is rendered white through a CSS filter for legibility on the dark surface.

- `aws.svg`: `amazonwebservices/amazonwebservices-original-wordmark.svg`
- `google-cloud.svg`: `googlecloud/googlecloud-original.svg`
- `azure.svg`: `azure/azure-original.svg`
- `kubernetes.svg`: `kubernetes/kubernetes-original.svg`
- `oracle.svg`: `oracle/oracle-original.svg`
- `kubernetes-mono.svg`: derived here from `kubernetes-original.svg` for the opening's marks row: the two paths merged into one single-colour path with `fill-rule="evenodd"`, so the wheel's detail stays visible through a CSS colour filter. Geometry otherwise unchanged.
- `oracle-mark.svg`: `oracle-original.svg` with its viewBox cropped to the wordmark's bounds, so it can be sized like the other marks. Geometry unchanged.

The Zenith symbol is the project's existing master geometry, imported from `src/components/shell/brand-geometry.ts`.
